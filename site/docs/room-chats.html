What Customization Is Possible

  • Title — text only, via chat.rename. Emoji + name (e.g. "💠 Bling").
  • Personality — each room's system prompt / blueprint defines its voice.
  • Memory — each room has its own MEMORY.md.
Not possible: custom icons, per-chat themes, CSS, background images. Side-chat titles are text-only. Account-wide appearance settings apply to all chats equally.

Room Blueprints

Each room is defined by a blueprint markdown file with its personality, tools, setup flow, and mill specs. Blueprints ship with {{TOKENS}} only — never PII.
