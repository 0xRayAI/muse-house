Bling Shop

The house shop. Trinkets (cosmetics), gizmos (one-off utilities), delights (surprises). The Bling room never charges and never sees card numbers.

How Purchases Work

  1. User browses the catalog at /bling.html.
  2. Stripe Checkout creates a payment session (we never see card numbers).
  3. Signature-verified webhook confirms payment.
  4. Fulfillment happens in the user's rooms — never just a web page.
Honesty rule: unfinished items stay "coming soon." Never take payment on unbuilt bling. Catalog copy describes only what installation really does.

Fulfillment Types

  • Voice Pack — 6 voices, hear-then-pick in the Bling room, briefing cron updated.
  • Emoji Packs — whole-house emoji sets, one-tap switch renames all 9 rooms.
  • Year-in-Review — real report built from the house board, posted in-chat.
  • Mystery Drop — random sticker posted inline.
