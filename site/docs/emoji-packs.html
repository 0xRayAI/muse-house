Pack Structure

Every pack defines all 9 rooms. Emojis must be real Unicode characters — side-chat titles are text-only.

{
  "id": "neon-nights",
  "name": "Neon Nights",
  "emojis": {
    "Bling": "💠", "Money": "🤑", "Art": "🌌",
    "Home": "🌉", "Travel": "🛸", "Coach": "💥",
    "Game": "🕹️", "Health": "💗", "Dev": "🔌"
  }
}

Switching Flow

  1. User taps a pack in the selector buttons.
  2. Button text arrives as user message (e.g. "💠 Neon Nights — neon-tube energy").
  3. Agent parses pack name, looks up 9 emojis.
  4. Agent calls chat.rename for all 9 side chats: "{emoji} {RoomName}".
  5. Confirm: "All 9 rooms now wearing [pack name]."
Use the Picker Panels pattern for the selector UI.
