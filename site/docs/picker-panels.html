Picker Panels

How selectors work in Muse House rooms — for builders.

The Two Pieces

Every selector has two parts:

  • Browser panel (HTML widget) — rich visual cards for looking at options. Display-only; taps don't trigger actions.
  • Selector buttons — plain text buttons that actually work. One tap applies the choice.

Building a Selector

Step 1: Define the options

Each option needs a name, a short descriptor, and the value to apply.

packs = {
    "house-original": {"Bling": "✨", "Money": "💸", ...},
    "neon-nights":    {"Bling": "💠", "Money": "🤑", ...},
}

Step 2: Create the buttons

muse.create_options(options=[
    "✨ House Original — the classic 9",
    "💠 Neon Nights — neon-tube energy",
    "🪩 Midnight Diner — coffee at 2am"
])
Rules: single line only (no \n, no <br>); no bold or formatting; emojis work — put the signature emoji first; keep it short.

Step 3: Handle the tap

When the user taps, the button text arrives as their message. Parse the name, apply the change:

# "💠 Neon Nights — neon-tube energy" arrives
pack = match_pack(user_message)  # → "neon-nights"
rename_all_rooms(pack.emojis)    # chat.rename × 9

Step 4 (optional): Browser panel

For a richer preview, build an HTML widget with cards. Use theme CSS variables (--hatch-widget-text, --hatch-widget-surface, etc.). Taps update visual state only — they cannot trigger agent actions.
