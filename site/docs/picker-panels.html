Picker Panels

Selectors that let users pick from options — voices, emoji packs, themes — right in chat.

The Two Pieces

  • Browser panel (HTML widget) — rich visual cards. Display-only; taps don't trigger actions.
  • Selector buttons (muse.create_options) — plain text buttons. One tap applies the choice.

Building a Selector

muse.create_options(options=[
    "✨ House Original — the classic 9",
    "💠 Neon Nights — neon-tube energy",
    "🪩 Midnight Diner — coffee at 2am"
])
Rules: single line only — no \n, \r\n, U+2028, or U+2029 (all render as one line). No bold or HTML. Emojis work — put the signature emoji first.

Handling the Tap

The button text arrives as the user's message. Parse it, apply the change, confirm.
